# Инструкция по обновлению сайта на GitHub Pages

В этой папке находится готовая, юридически безопасная версия сайта со всеми новыми функциями:
- ИИ Google WeatherNext 3.0 на 14 дней (2 полные недели)
- 30-дневный гибридный суперпрогноз (WeatherNext + ECMWF SEAS5)
- Интерактивная метеообсерватория (NASA VIIRS, MODIS, осадки NASA AIRS, радар RainViewer HD 512px, термокарты и градиенты)
- Поддержка Краснодара и 18 опорных метеостанций ВМО
- 100% юридическая безопасность (без слова VPN, корректные формулировки ВМО и защита от претензий)

---

## Как обновить сайт на GitHub Pages (за 2 минуты):

1. Откройте в браузере ваш репозиторий GitHub с сайтом (например, `meteocenter-rf.github.io`).
2. Нажмите кнопку **Add file** -> **Upload files**.
3. Перетащите в окно браузера файлы из этой папки:
   - `index.html`
   - `favicon.svg`
   - `.nojekyll`
4. Внизу страницы нажмите зеленую кнопку **Commit changes**.
5. Подождите 30–60 секунд — сайт обновится автоматически по вашему адресу!
