КАК ЗАГРУЗИТЬ САЙТ НА GITHUB ЗА 20 СЕКУНД:

1. Откройте в браузере страницу загрузки файлов в ваш репозиторий:
   https://github.com/meteocenter-rf/meteocenter-rf.github.io/upload/main

2. Перетащите мышкой из этой папки файлы прямо в окно браузера GitHub:
   - index.html (главный файл сайта)
   - favicon.svg (иконка)
   - robots.txt
   - .nojekyll

   (Или можете перетащить только один файл index.html — весь сайт полностью автономно работает в нём одном!).

3. Внизу страницы нажмите зеленую кнопку:
   "Commit changes"

Готово! Через 1 минуту сайт обновится по адресу:
https://meteocenter-rf.github.io/
